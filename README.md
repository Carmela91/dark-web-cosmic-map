# Dark Web Cosmic Map

An interactive large-scale visualization of the Dark Web ecosystem based on graph analytics and network science principles.

## 🌐 Live Demo

**Interactive Visualization:**

https://dark-web-csmic-map.netlify.app

## Overview

The Dark Web Cosmic Map represents the structure of a large-scale Dark Web dataset as a navigable cosmic network.

The visualization highlights:

- Large Connected Component (LCC)
- Host-level relationships
- Isolated communities
- Directory hubs
- Clearnet leak connections
- Multi-seed collection signals
- Temporal intelligence patterns
- Anomaly detection layers

Developed as part of the **Dark Web Cosmic Web** research project.

The Dark Web Cosmic Map explores alternative approaches for representing large-scale Dark Web ecosystems through graph-based visual analytics.

The project combines:

- Dark Web crawling
- Network science
- Threat intelligence
- Graph analytics
- Interactive visualization

into a single exploratory environment.
